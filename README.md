## 🏛️ v7.5.0 重磅升级亮点 (Release Highlights)

在 **v7.5.0** 中，系统迎来了操盘台视觉体系、行情渲染引擎、移动端交互体验与风控数学模型的重大跨越：

### 1. 🪙 换装经典比特币品牌微标与系统定名
- 全网统一更名为 **「R20量子交易系统」**；
- 界面全面换装经典金橙色比特币微标 **`₿`**，确立数字资产原生量化系统的极客品牌质感。

### 2. ⚡ TradingView 官方轻量级引擎本地集成（彻底免翻墙直连秒开）
- **0 外部跨域依赖**：引入 TradingView 官方开源的 `lightweight-charts v5` 核心库并纯本地打包，彻底解决传统 TradingView 在国内不开 VPN 无法加载或白屏的痛点，国内全网络 **0 延迟直连秒开**；
- **150 根高密度时序 K 线**：后端接口扩容并释放，彻底填满 PC 端宽屏视口，告别此前左侧大片空白的尴尬；
- **OKX 官方同款深邃纯净风**：采用深黑底色（`#0C0D12`）与极淡水平分割线，完全隐藏杂乱垂直网格；
- **蜡烛实体加宽加厚（`barSpacing: 11`）**：实体饱满宽大、上下影线落差鲜明，告别干瘪细小；
- **毫秒级 Tick 驱动与倒计时标尺**：每秒由真实盘口驱动最新 K 线跳动，右轴配备每秒精准递减的周期收盘倒计时（如 `42:15`）。

### 3. 🧠 多指标独立共存自由组合（专为未来「视觉 LLM」形态推演打造）
- **打破单一指标互斥限制**：主图与副图指标支持任意多选并发点亮：
  - `MA`：MA5(金黄) / MA10(天蓝) / MA20(紫罗兰) 均线组；
  - `BOLL`：20 周期布林带上中下轨（UB/MB/LB）；
  - `VOL`：高对比度红绿成交量柱状图，新增 `VOL-MA5` 量价对比均线；
- **视觉多模态大模型（Vision LLM）友好架构**：为未来接入 GPT-4o / Qwen-VL 进行截图直读 K 线形态（头肩顶、双底、旗形整理、量价背离）提供高对比度、无遮挡的标准图像支持。

### 4. 📱 移动端 2x2 网格与 PC 端黄金比例 Bento HUD 资产卡舱
- **移动端 2x2 网格**：在手机小屏上呈现上下两行、一行两个的对称专业卡舱，紧凑大方、不换行不溢出；
- **PC 端立体化方正比例**：高度释放至 160px~175px，大号资产字标（`text-3xl / 4xl`）配以保证金占用率进度条、全网实盘验证徽章，彻底告别宽屏下的“扁长条带”感。

### 5. 🎯 四维交易线与真实数学风控测算控制台
- **TradingView 原生价格线**：持仓成本线（实线）、云端止损线（SL 玫瑰红虚线）、云端止盈线（TP 翡翠绿虚线）实时贴附于图表；
- **真实美元金额测算（Bug 彻底根治）**：
  - 有持仓时：严格联动真实持仓保证金与杠杆倍数（$\text{实际保证金} \times \text{杠杆} \times \Delta P\%$），精准测算预期盈利与最大风险；
  - 观望试算时：统一按标准单笔风控额（100 USDT 保证金，3x 杠杆）推算，彻底消除了此前误算导致的数千美元虚标假数据；
  - 严格执行 $R:R \ge 2.0$ 盈亏比合规门禁提示。

### 6. 🛡️ OKX OAuth 账户一键解绑与无缝换号
- 安全中心支持一键解绑本地 Token 凭据并重新申请设备授权码，免除手动修改文件配置的烦琐流程。

## 🚀 快速启动指南

### 1. 克隆代码与进入工作区
```bash
git clone https://github.com/555cute/r20-quantum-trader.git
cd r20-quantum-trader
```

### 2. 环境配置
复制环境变量模板并填入您的 OKX API 与大模型凭据：
```bash
cp .env.example .env
vim .env
```

### 3. 安装依赖与启动服务
```bash
# 1. 后端依赖安装与启动
pip install -r requirements.txt
python -m uvicorn r20_backend.app:app --host 0.0.0.0 --port 8080

# 2. 前端开发或构建生产包
cd frontend
npm install
npm run build
```

访问 `http://localhost:8080/` 即可进入全新的 **R20量子交易系统** 操盘台。
