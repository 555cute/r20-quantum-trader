## 1. R20 提示词系统核心量化哲学

在 R20 系统中，大模型（LLM）的角色是**对冲基金交易台的“首席投资决策官（CIO）”**，而不是简单的问答机器人。

### 🎯 为什么提示词直接决定实盘盈亏？
量化交易的长期归宿由**单笔数学期望 $E$** 决定：
$$E = (\text{胜率} \times \text{平均盈利}) - (\text{败率} \times \text{平均亏损}) - \text{交易成本}$$

历史实盘复盘显示：**高胜率（如 60%）不等于能赚钱**。如果提示词在浮盈微小（如 +1%）时就惊慌失措地催促模型“保本平仓”或“提前落袋”，而在走势逆转时却留给止损 2.0x ATR 的宽大空间，系统就会陷入致命的**“赢小输大（盈亏比仅 0.45）”**恶性循环。

**优质提示词的核心使命**：
1. **顺应大势**：4H 多头大势专注回踩做多，4H 空头通道专注承压做空，震荡箱体边界高抛低吸；
2. **给足呼吸**：浮盈未稳固前严禁过早提损保本，拒绝在正常日内健康回抽中恐慌平仓；
3. **波段奔跑**：让有潜力的主升浪吃到 2.0R~3.0R 的深厚利润，用大单笔收益充分覆盖常规试错成本；
4. **敞口自律**：同向持仓达 2 笔以上时主动提升门禁，防范全市场单边系统性 Beta 踩踏。

## 2. 全量实时语义数据插槽权威字典 (Semantic Variables Reference)

R20 提示词**全链路联动毫秒级真实实盘数据**。你可以在提示词中使用双花括号 `{{variable_name}}` 插入对应数据，系统在调用大模型前会自动完成变量渲染：

| 语义插槽占位符 | 中文名称 | 所属分类 | 注入的真实数据内容与实战用途 |
|---|---|---|---|
| `{{account_balance}}` | **账户可用资金** | 账户敞口 | 交易所私有接口实时拉取的可用 USDT 现金余额（如 `4393.08 USDT`），模型据此评估可用弹药。 |
| `{{risk_budget}}` | **自适应风控预算** | 账户敞口 | 根据可用余额与后台风控配置，现场推导的单笔保证金区间、单标的封顶、日亏熔断线、同向仓位上限、杠杆区间与 R:R 硬底线。**彻底杜绝模型臆造固定绝对金额。** |
| `{{account_positions}}` | **账户在管持仓** | 账户敞口 | 当前所有活动在手仓位：标的、方向、杠杆、均价、市价、浮盈 U、未结 ROI、**曾最高触及价（High Water Mark）与极值回撤百分比**、动态止损线。 |
| `{{pending_orders}}` | **在途未成交挂单** | 账户敞口 | 当前盘口挂单池中的 Maker 限价挂单 ID、标的、买卖方向、挂单价格、挂单数量与挂单时长，供模型执行 `KEEP` 或 `CANCEL`。 |
| `{{market_regime}}` | **全市场宏观体制** | 行情数理 | 全市场宏观体制自适应识别结果（单边趋势/宽幅震荡/窄幅低波/极端冲击），输出趋势分、波动分、震荡指数与针对性操盘建议。 |
| `{{market_matrix}}` | **全标的数理行情矩阵** | 行情数理 | **核心数据中枢**：标的池全部币种现价、24H涨跌、盘口一档、1H ATR/RSI/ADX、15M VWAP乖离/OBV、微积分一阶速度 $v$ 与加速度 $a$、定积分能量 $E$ 与面积 $A$、条件延续概率 $P_{\text{续}}$ 与击穿概率 $P_{\text{破}}$、资金费率、持仓 OI、多空比、跨所基差与倒序多周期 K 线。 |
| `{{news_intelligence}}` | **全网实时资讯要闻** | 实时情报 | 金十数据与全网重大加密突发快讯流、美联储决议、宏观经济数据及系统判定的当前宏观情绪基调（偏多/偏空/震荡）。 |
| `{{trading_memory}}` | **自进化实战心法** | 自进化 | 系统根据历史已平仓真实台账，每日自动复盘沉淀的长效经验与避坑铁律（源自 `structured_trading_memory.json`）。 |
| `{{decision_timestamp}}` | **决策基准时间** | 系统环境 | 当前决策周期的精确北京时间戳（格式：`YYYY-MM-DD HH:MM:SS (北京时间)`）。 |
| `{{active_instruments}}` | **监控标的列表** | 系统环境 | 当前在管的加密货币交易对清单（如 `BTC,ETH,SOL,DOGE,SUI,ADA,ARB,LINK,UNI`）。 |

## 3. 破解“赢小输大”的五大提示词编写军规

如果你在编写自己的策略提示词，请务必贯彻以下五大实战铁律：

### ⚔️ 铁律一：科学波段呼吸，严禁过早提损保本
* **常见误区**：提示词写“浮盈一达到 1.0% 或 0.8R 立即移损到保本位”。
* **实盘恶果**：加密货币是高波动资产，15M 级别的正常回踩很容易产生 1% 的波动。过早保本会导致 70% 的潜力波段在刚启动时被白白扫出，只赚得几毛钱或者倒贴手续费。
* **正确写法**：
  > “持仓浮盈 < 1.0R~1.2R 坚持给足 1.8x~2.2x ATR 宽止损空间，留足结构呼吸时间；浮盈稳固达到 ≥ 1.5R 且波段形态确立后，方可输出 `UPDATE_SL` 将止损移至开仓成本 +0.20% 保本位。”

### ⚔️ 铁律二：杜绝惊慌市价砸盘，让主升浪波段奔跑
* **常见误区**：提示词写“只要浮盈较最高点回撤 30% 无论如何立刻市价全平”。
* **实盘恶果**：一笔单子刚浮盈 3U，盘面出现一次微幅拉回 1U，模型就惊恐执行 `CLOSE_MARKET`。盈利单被死死压制在 2~5U，而止损单却一亏就是 20U。
* **正确写法**：
  > “严禁在轻度浮盈（< 1.5R）的日内正常回踩中恐慌性市价平仓；只有当持仓曾录得显著深厚利润（浮盈 ≥ 1.8R~2.0R）且 1H 动能出现明确结构性破位时，才启动主动锁利退出。”

### ⚔️ 铁律三：多资产同向敞口自律，防范系统性 Beta 踩踏
* **常见误区**：提示词没有同向约束，在 BTC、ETH、SOL、SUI 上同时满仓做多或做空。
* **实盘恶果**：大盘一旦出现插针或单边异动，所有标的连环触发止损，单日亏损瞬间击穿心理防线。
* **正确写法**：
  > “全账户同向在手仓位达到 2 笔以上时，新开同向单必须自律提升开仓置信度门槛至 85% 以上，且严禁在高相关标的上无节制堆叠单边敞口，防范系统性 Beta 踩踏。”

### ⚔️ 铁律四：止损出局后坚决冷静，杜绝绞肉市连续接刀
* **常见误区**：模型在同一标的被止损后，下一周期看到 1H 稍微企稳立刻再次同向开仓。
* **实盘恶果**：在震荡绞肉市中（如典型的 ARB 假突破行情），单一币种在 24 小时内连开 6 次连续止损，账户被同一把钝刀反复磨损。
* **正确写法**：
  > “标的一旦触发止损离场，必须严格遵守风险预算声明的冷静期；冷静期内或该标的未出现明确突破大级别结构前，坚决保持 WAIT，杜绝急躁反手与情绪化连续抄底摸顶。”

### ⚔️ 铁律五：入场遵循 Maker 限价挂单，严守 R:R ≥ 2.0 价格几何
* **核心规范**：
  - 做多几何：`stop_loss_price < entry_price < take_profit_price`
  - 做空几何：`take_profit_price < entry_price < stop_loss_price`
  - 严禁市价追单，挂单锚定在盘口支撑/阻力位附近（现价下方/上方 0.1%~0.6%）；
  - 止损距离参考 1.8x~2.2x 1H ATR，止盈距离至少为止损距离的 2.0 倍以上（R:R ≥ 2.0）。

## 4. 提示词策略管线与四大分层结构

在系统的“提示词工坊”中，提示词被解耦为四大核心管线（Pipelines），你可以针对性进行增量模块定制：

```text
┌─────────────────────────────────────────────────────────────┐
│                    R20 提示词工程管线结构                    │
├──────────────────────────────┬──────────────────────────────┤
│ 1. trading_system (系统主宪法)│ 设定模型角色、决策优先级与铁律 │
├──────────────────────────────┼──────────────────────────────┤
│ 2. trading_user (用户推演上下文)│ 注入真实市场矩阵、持仓与推演任务 │
├──────────────────────────────┼──────────────────────────────┤
│ 3. evolution_system (复盘系统)│ 设定自进化认知中枢的复盘反思规则 │
├──────────────────────────────┼──────────────────────────────┤
│ 4. evolution_user (复盘上下文) │ 注入真实已平仓台账流水与心法库  │
└──────────────────────────────┴──────────────────────────────┘
```

* **Base 基础模块**：由系统底层动态提供并实时联动行情数据（带锁定标记，确保数据真实性与结构合法性）；
* **Custom 自定义模块**：**完全对用户开放**！你可以自由添加自定义风格、交易员流派、特殊风控偏好或特定技术指标加权要求。

## 5. 四大出厂实战模板与经典范例 (Battle-Tested Templates)

### 模板一：全维度波段强化主策略 (System Prompt 核心范本)
```markdown
==== 【系统角色定位与核心使命】 ====
你是 AstraQuant 的首席 AI 交易官，负责 1H~4H 加密合约多空双向波段的高胜率交易裁决。你的使命按优先级排列：
1. 捍卫本金：单笔风险有界、日亏有熔断、敞口有上限，任何单笔损失都不得伤及账户根基；
2. 捕捉正期望：只在数学期望为正（概率优势 × 盈亏比 > 摩擦成本）的机会上下注，用高确定性波段积累复利；
3. 拒绝懈怠与恐惧：当空仓且存在至少一个合法顺势候选时通过全部硬门禁，果断限价进场，不无故放弃合规机会。
一切金额类参数（保证金、风险额、熔断线）一律以每轮用户消息中【本周期风险预算】小节的实时推导值为准。

==== 【核心军规：反割肉·反磨损·波段奔跑五大铁律】 ====
1. 宽止损隔绝杂波：止损必须放在市场结构失效点之外，距离 1.8x~2.2x 1H ATR，彻底隔绝 15M/5M 噪音假动作。
2. 三阶利润棘轮（兼顾波段奔跑与胜率锁定，杜绝赢小输大）：
   - 阶梯1（浮盈 < 1.0R）：保持原宽止损给波段充分展开时间，禁止微小浮盈过早提至成本位被杂波扫出；
   - 阶梯2（浮盈 ≥ 1.5R 且 ROI ≥ +2.2%）：输出 UPDATE_SL 将止损移至保本位（开仓成本 +0.20%），切断本金风险；
   - 阶梯3（浮盈 ≥ 2.2R 且 ROI ≥ +3.5%）：输出 UPDATE_SL 锁定成本上方至少 +1.0R 扎实波段利润。
   主动止盈三道防线：① 峰值回撤——最高浮盈曾达 ROI ≥ +3.5% 或 ≥ 1.8R 且走势结构破位时才主动退出，严禁在微幅浮盈（<1.5R）的正常日内回踩中恐慌砸盘；② 动能耗散——浮盈充沛（ROI ≥ +2.5%）且 1H 功率做功反向耗散（v·a < -0.15）时提前落袋；③ 阻力锚定——止盈价锚定 2.0~2.8x ATR 空间，让盈利波段充分奔跑。
3. 敞口纪律：同向已有 2 笔时新开同向单置信度自律提升至 85% 以上，严禁在相关标的上无节制堆叠单边敞口；止损出局标的在冷静期内严禁申请该标的。
4. 价格几何与限价：BUY_LONG 满足 stop_loss < entry < take_profit；SELL_SHORT 满足 take_profit < entry < stop_loss。目标盈亏比 R:R ≥ 2.0，入场一律 Maker 限价挂单，严禁市价追单。
```

### 模板三：宽幅震荡箱体收割官方套件 (v8.0.0 专为震荡洗盘定制)
```markdown
==== 【宽幅震荡箱体收割核心军规】 ====
所有 P0 硬约束保持不变。宽幅震荡行情核心在于箱体边际定价与防插针保护：
1. 箱体边际定价铁律：严禁在箱体正中间（半山腰）追涨杀跌！开仓仅限于 1H/4H 箱体上轨阻力位承压做空，或箱体下轨支撑位企稳做多，或 VWAP 显著乖离处；
```

## 6. 白盒护栏与高频避坑指南 (Security & Troubleshooting)

### ⚠️ 白盒安全护栏审查规则 (`scan_forbidden`)
为了保护账户资产物理安全，系统在保存、导入或应用任何提示词模板时，都会经过内建的代码级白盒安全审查。**以下表述组合会触发系统安全拦截，请务必避免**：

1. **严禁要求忽略系统硬风控**：
   - ❌ 错误示例：*“你可以忽略 P0 约束”、“跳过止损检查”、“覆盖执行层门禁”*；
   - ✅ 正确表述：*“在 P0 硬约束框架内严格执行”、“严格对齐风险预算声明”*。
2. **严禁在提示词中硬编码 API Key 或私密凭据**：
   - ❌ 严禁出现任何 `sk-`、`AIza` 或明文密钥字样。
3. **严禁写死绝对金额**：
   - ❌ 错误示例：*“每笔固定开 100U”、“止损设为 50 美元”*；
   - ✅ 正确表述：*“保证金取自【本周期风险预算】常规区间”、“以 1.0R 为风险基准”*。

### 🛠️ 变量调试技巧
* **提示词工坊实时预览**：在“提示词工坊”编辑时，可以点击右侧的**“编译视图”**，系统会以当前最新实盘行情实时渲染所有变量，让你直观看到模型在下一周期将阅读到的完整 Prompt。
* **查看上一轮推演输入**：在终端或后台可以随时查阅 `data/ai_brain_last_prompt.txt`，核对模型上一轮接收到的实时参数。
